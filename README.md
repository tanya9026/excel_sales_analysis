# Excel Sales Analysis Dashboard

## Project Overview
This project analyzes fictional sales data from January to June 2026 using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel formulas
- Charts and KPI cards

## Key Performance Indicators (KPIs)
- Total Sales: ₹5,19,100
- Total Profit: ₹1,43,360

## Business Insights
- Top-selling product by sales value: Laptop
- Best-performing region by sales: West
- Highest-sales month: April

## Project Objectives
- Analyze sales and profit performance.
- Compare sales across products and regions.
- Identify monthly sales trends.
- Present findings through a dashboard.

## Files Included
- Excel workbook with sales data, Pivot Tables, dashboard, and business insights.

**Note:** The dataset is fictional and created for learning and portfolio purposes.
